# Python Flask CRUD App (SQLite)

Aplicación CRUD desarrollada con **Python**, **Flask** y **SQLite**, que permite gestionar usuarios desde una interfaz web construida con **Bootstrap 5**.  
Este proyecto sirve como práctica de desarrollo backend, manejo de rutas, plantillas Jinja2 e interacción con bases de datos.

---

## 🚀 Tecnologías utilizadas

- Python 3  
- Flask  
- SQLite  
- Bootstrap 5  
- HTML + Jinja2
